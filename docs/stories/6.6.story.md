### Dev Notes

**Testing Standards**

*   **File Location:** All test files MUST be co-located in the same folder as the source file they are testing. [Source: docs/prd/epic-6-testing-refactor-and-standardization.md]
*   **File Naming Convention:** All test files must follow the `*.test.ts` naming convention. [Source: docs/prd/epic-6-testing-refactor-and-standardization.md]
*   **Test Structure (Arrange, Act, Assert):** All tests must be structured with the following three distinct sections for clarity and consistency. [Source: docs/prd/epic-6-testing-refactor-and-standardization.md]
*   **Mocking Strategy:** Use `jest.fn()` for mocking server actions, API calls, and custom hooks. [Source: docs/prd/epic-6-testing-refactor-and-standardization.md]
