### Story
**As a** user,
**I want** to enter my phone number and download my e-certificate,
**so that** I can receive my digital certificate.

### Acceptance Criteria
1. The `EcertificateTab` contains a phone number input and a "Confirm & Download" button.
2. The button is disabled until a valid phone number is entered.
3. Clicking the button calls the `/api/certificate` endpoint with the user's `name`, `town`, and `phone`.
4. Upon a successful API response, the PDF download is automatically triggered.
5. The user's `name`, `town`, and `phone` are stored in local storage for pre-filling.

### Tasks / Subtasks
- [ ] Implement the UI for the `EcertificateTab` component.
- [ ] Add state management for the phone number input.
- [ ] Implement validation for the phone number.
- [ ] Create a function to call the backend API.
- [ ] Implement the logic to trigger the PDF download.
- [ ] Save user data to local storage on success.

### Dev Notes
