### Story
**As a** developer,
**I need** an API endpoint to create a certificate record,
**so that** user data and certificate numbers can be stored.

### Acceptance Criteria
1. A new API endpoint (e.g., `/api/certificate`) is created.
2. The endpoint accepts `name`, `town`, and `phone` in the request body.
3. A unique `certificateNumber` is generated for each request.
4. A new record is inserted into the `users` table with the provided data and the generated `certificateNumber`.
5. The endpoint returns a success response upon successful creation.

### Tasks / Subtasks
- [ ] Create a new file for the API route (e.g., `app/api/certificate/route.ts`).
- [ ] Implement the POST handler for the endpoint.
- [ ] Add validation for the incoming request body.
- [ ] Implement logic to generate a unique certificate number.
- [ ] Use Prisma or a similar ORM to create the new user record.

### Dev Notes
- Ensure proper error handling is in place for database operations.
- The certificate number generation should be robust enough to avoid collisions.
