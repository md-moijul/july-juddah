### Story
**As a** developer,
**I need** a Next.js Server Action to create a certificate record,
**so that** user data and certificate numbers can be securely stored while preventing duplicate entries.

### Acceptance Criteria
1.  A Next.js Server Action is created to handle certificate generation requests.
2.  The action accepts `name`, `town`, and `phone` as input.
3.  When the action is called:
    *   It first queries the `users` table to check for an existing user with the same `phone` number.
4.  **If no user with the provided phone number exists:**
    *   A unique `certificateNumber` is generated.
    *   A new record is inserted into the `users` table with the provided `name`, `town`, `phone`, and the generated `certificateNumber`.
    *   The action returns a success response (`{ success: true, certificateNumber: '...' }`).
5.  **If a user with the provided phone number already exists:**
    *   No new user record is created.
    *   The action returns a failure response (`{ success: false, error: 'This phone number has already been used to generate a certificate.' }`).
6.  Input validation is implemented to handle cases where `name`, `town`, or `phone` are missing or invalid.

### Dev Notes
- The Server Action should be implemented using Next.js's Server Action conventions for improved security and developer experience.
- Use the existing Drizzle schema (`schema.ts`) for all database interactions.
- The return type of the action should be a structured object to allow the client to easily handle success and failure states:
  ```typescript
  type ActionResult = {
    success: boolean;
    certificateNumber?: string;
    error?: string;
  };
  ```
- Ensure that the database logic is properly awaited and that any potential errors are caught.
