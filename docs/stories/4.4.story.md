# Story 4.4: Implement E-Certificate Download with OTP Verification

**Status:** Ready for Review

**Story:**
As a user, I want to verify my phone number using an OTP to download my e-certificate, so that my identity is confirmed and I can securely receive my document.

**Acceptance Criteria:**
1.  Clicking the "Download E-certificate" button on the `/generate` page opens a modal.
2.  The modal contains an input field for a phone number, a "Terms & Conditions" checkbox, a Google reCAPTCHA v2 checkbox, and a "Send OTP" button.
3.  The "Send OTP" button is disabled until a valid phone number is entered, the T&C is checked, and the reCAPTCHA is successfully verified.
4.  Clicking "Send OTP" calls a mocked API endpoint that simulates sending an OTP.
5.  The modal UI updates to show an input field for the OTP and a "Verify & Download" button.
6.  Submitting the correct OTP (a hardcoded value for now) triggers the automatic download of a sample personalized PDF.
7.  If the OTP is incorrect, an error message is displayed.

**Tasks / Subtasks:**

- [x] Implement the UI for OTP entry.
