# Story 4.4: Implement E-Certificate Download with OTP Verification

**Status:** Draft

**Story:**
As a user, I want to verify my phone number using an OTP to download my e-certificate, so that my identity is confirmed and I can securely receive my document.

**Acceptance Criteria:**
1.  Clicking the "Download E-certificate" button on the `/generate` page opens a modal.
2.  The modal contains an input field for a phone number, a "Terms & Conditions" checkbox, and a "Send OTP" button.
3.  The "Send OTP" button is disabled until a valid phone number is entered and the checkbox is ticked.
4.  Clicking "Send OTP" calls the backend API to send an OTP to the user's phone.
5.  The modal UI updates to show an input field for the OTP and a "Verify & Download" button.
6.  Submitting the correct OTP to the verification endpoint triggers the automatic download of the personalized PDF.
7.  The verified phone number is stored in the database against the certificate record.
8.  If the OTP is incorrect, an error message is displayed.

**Tasks / Subtasks:**
- [ ] Create a new React component for the OTP verification modal.
- [ ] Add state management to the `/generate` page to control the modal's visibility.
- [ ] Implement the form within the modal (phone input, checkbox).
- [ ] Implement client-side validation for the phone number format.
- [ ] Implement the `onClick` handler for "Send OTP" to call the `/api/send-otp` endpoint.
- [ ] Implement the UI for OTP entry.
- [ ] Implement the `onClick` handler for "Verify & Download" to call the `/api/verify-otp` endpoint.
- [ ] On successful verification, trigger the file download and update the database with the phone number.
- [ ] Handle API error states and display appropriate messages to the user.

**Dev Notes:**
- The download should be initiated from the client-side after a successful verification response from the backend.
- Ensure the T&C checkbox is legally compliant.
