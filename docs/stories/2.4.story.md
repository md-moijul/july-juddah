## Description

Create the features section, dynamically rendering each feature from the `features` array in `content.json`. Each feature should have an icon, title, and description, all styled according to `style.json`.

## Acceptance Criteria

1.  The features section is implemented as a new component at `apps/web/src/components/sections/features-section.tsx`.
2.  The component dynamically renders all features listed in the `features` array from `apps/web/src/data/content.json`.
3.  Each feature item displays an icon, a title, and a description.
4.  The styling of the features section (layout, colors, fonts) matches the specifications in `apps/web/src/data/style.json`.
5.  The `FeaturesSection` component is integrated into the main landing page at `apps/web/src/app/page.tsx`.
