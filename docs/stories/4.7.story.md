### Dev Notes

**Database Schema Specification**

**Context:** The user has already created the Vercel Postgres database and has pulled the environment variables into a `.env.local` file. The developer must use the `POSTGRES_URL` environment variable for the connection string.

**Table 1: users**
* **id:** A unique, auto-incrementing integer that serves as the primary key.
* **certificateNumber:** A unique text string that cannot be empty.
* **name:** A text string for the user's full name, which cannot be empty.
* **town:** A text string for the user's town, which can be empty (nullable).
* **phone:** A unique text string for the user's phone number.
* **isOtpVerified:** A boolean value with a default of `false`, cannot be empty.
* **referrerId:** An integer that links to the `id` of another user in this same table (self-referencing). This value can be empty (nullable).

**Table 2: orders**
* **id:** A unique, auto-incrementing integer that serves as the primary key.
* **shippingAddress:** A text string for the order's shipping address, which cannot be empty.
* **userId:** An integer that links to the `id` column in the `users` table, cannot be empty.

**Table Relationships:**
* **User to Orders:** One-to-Many.
* **User to Referrer:** One-to-One (a user can have one referrer).
* **User to Referred Users:** One-to-Many (a user can refer many others).
