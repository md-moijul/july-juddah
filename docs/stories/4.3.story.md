# Story 4.3: Update PDF Generation Service with Dynamic Data

**Status:** Draft

**Story:**
As a developer, I want to update the backend PDF generation service to use the new certificate template and dynamically insert the user's name, district, and a unique certificate number.

**Acceptance Criteria:**
1.  The PDF generation service loads the new certificate template (`8.pdf`).
2.  The service accepts `name` and `district` as input parameters.
3.  The "[Your Name]" placeholder in the PDF is replaced with the provided `name`.
4.  The "[Town Name]" placeholder in the PDF is replaced with the provided `district`.
5.  A unique certificate number is generated for each request.
6.  The generated certificate number is placed onto the designated area in the PDF.
7.  The service returns the generated PDF as a file or data stream.
8.  The generated certificate data (name, district, certificate number) is saved to the database.

**Tasks / Subtasks:**
- [ ] Add the new PDF template `8.pdf` to the project assets.
- [ ] Update the PDF library (e.g., `pdf-lib`) code to load `8.pdf`.
- [ ] Modify the API endpoint for PDF generation to accept `name` and `district`.
- [ ] Implement the logic to find and replace the text placeholders for name and district.
- [ ] Integrate the unique certificate number generation logic from Story 4.1.
- [ ] Determine the coordinates for placing the certificate number and implement the drawing logic.
- [ ] Implement the database insertion logic to save the certificate record upon successful generation.

**Dev Notes:**
- The path to the new template `8.pdf` needs to be correctly resolved. It should be moved to `apps/web/public` or a similar assets folder.
- Font and styling for the dynamic text should match the certificate's design.

**QA Results:**
- Reviewed `apps/web/src/app/generate/page.tsx` and refactored `handleDownloadEcertificate` into a custom hook `useCertificateDownload` located at `apps/web/src/hooks/useCertificateDownload.ts`. This improves code organization and readability by centralizing download logic and state management.
