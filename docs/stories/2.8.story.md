## Story

As a user, I want to see a final, compelling call-to-action at the bottom of the page, so that I am clearly prompted to proceed with the main action of generating my certificate.

## Acceptance Criteria

1.  A new React component named `FinalCtaSection` is created in the `apps/web/src/components/sections/` directory.
2.  The component must be responsive and display correctly across all screen sizes (mobile, tablet, desktop).
3.  The component must render the `headline`, `subheadline`, and `cta` button text as defined in the `finalCta` section of `content.json`.
4.  All styling (e.g., typography, colors, spacing, button styles) must be implemented using Tailwind CSS and adhere to the specifications in `style.json`.
5.  The CTA button within the section must be the reusable `Button` component from the established UI library (`shadcn/ui`).
6.  The `FinalCtaSection` component is imported and rendered in the main `LandingPage` component (`apps/web/src/app/page.tsx`).
