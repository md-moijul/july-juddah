# Story 8.7: Implement Hard Copy Order Flow

**Status:** Draft

**Epic:** [Refactor User Data and State Management](docs/prd/epic-8-refactor-user-data-and-state-management.md)

**Story:** As a user, I want to be able to order a hard copy of my certificate by providing my shipping address, so that I can receive a physical copy.

**Acceptance Criteria:**

1.  The "Order Hard Copy" tab contains a form with input fields for `phone number` and `shippingAddress`.
2.  The `name`, `town`, and `phone` number fields are pre-populated from the `ZustandStore`.
3.  The form includes a confirmation checkbox that must be checked to enable the "Confirm Order" button.
4.  Clicking the "Confirm Order" button calls the new `createOrder` Server Action.
5.  A success message is displayed to the user after the order is successfully created.

**Tasks / Subtasks:**

-   [ ] Create the UI for the "Order Hard Copy" tab, including the form inputs and the confirmation checkbox.
-   [ ] Pre-populate the `name`, `town`, and `phone` fields from the `useUser` hook.
-   [ ] Implement the logic to enable/disable the "Confirm Order" button based on the checkbox state.
-   [ ] Create an `onSubmit` handler for the form that calls the `createOrder` server action.
-   [ ] Display a success toast or message when the order is created successfully.

**Dev Notes:**

*   This story implements the final piece of the user-facing functionality for this epic.
*   Consider the user experience for the success message. It should be clear and reassuring.

**Testing:**

*   Manually test the full hard copy order flow:
    *   Verify the form is pre-populated correctly.
    *   Test the confirmation checkbox logic.
    *   Successfully submit an order and verify the success message.
