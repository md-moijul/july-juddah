# Story 8.7: Implement Hard Copy Order Flow

**Status:** Done

**Epic:** [Refactor User Data and State Management](docs/prd/epic-8-refactor-user-data-and-state-management.md)

**Story:** As a user, I want to be able to order a hard copy of my certificate by providing my shipping address, so that I can receive a physical copy.

**Acceptance Criteria:**

1.  The "Order Hard Copy" tab contains a form with input fields for `shippingAddress`.
2.  The `name`, `town`, and `phone` number fields are pre-populated from the `ZustandStore`.
3.  The form includes a confirmation checkbox that must be checked to enable the "Confirm Order" button.
4.  Clicking the "Confirm Order" button calls the new `createOrder` Server Action.
5.  A success message is displayed to the user after the order is successfully created.
6.  An error message is displayed if the order creation fails.
7.  The UI should be styled using ShadCN and Tailwind CSS to match the existing design of the application.

**Tasks / Subtasks:**

-   [x] Open the file `apps/web/src/components/HardCopyTab/index.tsx`.
-   [x] Update the component to render a form with a `textarea` for `shippingAddress` and a `checkbox` for confirmation.
-   [x] The `name`, `town`, and `phone` fields should be displayed as read-only text, pre-populated from the `useUser` hook.
-   [x] Implement the logic to enable/disable the "Confirm Order" button based on the checkbox state.
-   [x] Create an `onSubmit` handler for the form that calls the `createOrder` server action with the user data from the store and the shipping address from the form.
-   [x] Use a toast notification to display a success message when the order is created successfully.
-   [x] Use a toast notification to display an error message if the `createOrder` action returns an error.
