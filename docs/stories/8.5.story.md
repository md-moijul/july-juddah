# Story 8.5: Implement E-Certificate User Creation Flow

**Status:** Done

**Epic:** [Refactor User Data and State Management](docs/prd/epic-8-refactor-user-data-and-state-management.md)

**Story:** As a user, I want to be able to enter my phone number in the "E-certificate" tab and click a button to create my user record and download my certificate, so that I can complete the generation process.

**Acceptance Criteria:**

1.  The "E-certificate" tab contains a phone number input field and a "Confirm & Download" button.
2.  Client-side validation is implemented to ensure the phone number is in a valid format.
3.  Clicking the button calls the existing `createUser` Server Action with the user's name, town, and phone number from the `useUserStore`.
4.  If the `createUser` action returns a "phone number already exists" error, the error message is displayed to the user.
5.  On successful user creation, the new `userId` is saved to local storage.
6.  The `useUserStore` is updated with the new user data.
7.  The PDF download is initiated upon successful user creation.

**Tasks / Subtasks:**

-   [x] Update the UI for the "E-certificate" tab, including the phone number input and the button.
-   [x] Implement client-side validation for the phone number input.
-   [x] Create an `onClick` handler for the "Confirm & Download" button.
-   [x] In the handler, call the `createUser` server action, passing the required data from the `useUserStore` and the form.
-   [x] Implement error handling to display the specific error message for an existing phone number.
-   [x] In the success callback, save the new `userId` to local storage.
-   [x] Update the `useUserStore` with the new user data.
-   [x] Trigger the PDF download.
