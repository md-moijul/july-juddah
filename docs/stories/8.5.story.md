# Story 8.5: Implement E-Certificate User Creation Flow

**Status:** Draft

**Epic:** [Refactor User Data and State Management](docs/prd/epic-8-refactor-user-data-and-state-management.md)

**Story:** As a user, I want to be able to enter my phone number in the "E-certificate" tab and click a button to create my user record and download my certificate, so that I can complete the generation process.

**Acceptance Criteria:**

1.  The "E-certificate" tab contains a phone number input field and a "Confirm & Download" button.
2.  Client-side validation is implemented to ensure the phone number is in a valid format.
3.  Clicking the button calls the existing `createUser` Server Action with the user's name, town, and phone number.
4.  If the `createUser` action returns a "phone number already exists" error, the error message is displayed to the user.
5.  On successful user creation, the new `userId` is saved to local storage.
6.  The `UserDataContext` is updated with the new user data.
7.  The PDF download is initiated upon successful user creation.

**Tasks / Subtasks:**

-   [ ] Create the UI for the "E-certificate" tab, including the phone number input and the button.
-   [ ] Implement client-side validation for the phone number input.
-   [ ] Create an `onClick` handler for the "Confirm & Download" button.
-   [ ] In the handler, call the `createUser` server action, passing the required data from the context and the form.
-   [ ] Implement error handling to display the specific error message for an existing phone number.
-   [ ] In the success callback, save the new `userId` to local storage.
-   [ ] Update the `UserDataContext` with the new user data.
-   [ ] Trigger the PDF download.

**Dev Notes:**

*   This story builds on the refactored `CertificateForm` and the existing `UserDataContext`.
*   A toast notification or an inline error message would be appropriate for displaying the error.

**Testing:**

*   Manually test the following scenarios:
    *   Entering an invalid phone number.
    *   Entering a phone number that already exists in the database.
    *   Successfully creating a user and verifying the download starts.
