### Story
**As a** user,
**I want** to order a hard copy of my certificate by providing my shipping details.

### Acceptance Criteria
1. The `HardCopyTab` contains a form with `phone number` and `shippingAddress` inputs.
2. The `name`, `town`, and `phone number` fields are pre-filled from local storage if available.
3. A new API endpoint (e.g., `/api/order`) is created to handle hard copy orders.
4. Clicking the "Confirm Order" button calls the `/api/order` endpoint.
5. A new record is created in the `orders` table, linked to the user.

### Tasks / Subtasks
- [ ] Implement the UI for the `HardCopyTab` component.
- [ ] Add state management for the form fields.
- [ ] Implement logic to pre-fill data from local storage.
- [ ] Create the `/api/order` API endpoint.
- [ ] Implement the POST handler to create a new order in the database.
