## Description

Update the navigation bar to use the content from `content.json` and styling from `style.json`. This includes the logo, navigation links, and the main CTA button.


## Acceptance Criteria

1.  The navigation bar's logo, links, and CTA button text are loaded from `apps/web/src/data/content.json`.
2.  The navigation bar's styling (colors, fonts, spacing) is implemented according to `apps/web/src/data/style.json`.
3.  The navigation bar is fully responsive and matches the mobile and desktop designs.
4.  The CTA button in the navigation bar is functional and directs the user to the `/generate` page.
5.  All links in the navigation bar are functional and point to the correct sections or pages.
6.  The navigation bar is implemented as a reusable React component.
7.  The component is placed in the main layout to ensure it appears on all pages.
8.  The implementation uses Tailwind CSS for all styling, adhering to the project's standards.
9.  The code is clean, well-documented, and follows the established coding conventions.
10. The component is tested to ensure it renders correctly and all links and buttons work as expected.

## Dev Notes

*   **Component Location:** Create the new component at `apps/web/src/components/sections/navigation.tsx`.
*   **Content Source:** All text content (links, button text) and the logo URL should be fetched from `apps/web/src/data/content.json`. Do not hardcode any strings.
*   **Styling Source:** All styling must be implemented using Tailwind CSS utility classes, referencing the design tokens and color palette defined in `apps/web/src/data/style.json`.
*   **UI Library:** Utilize the existing `Button` component from `shadcn/ui` for the main CTA to ensure consistency.
*   **Routing:** Use the Next.js `Link` component for all internal navigation to enable client-side routing.
*   **Responsiveness:** Implement a mobile-first approach. The navigation should look great on small screens and then adapt for larger screens, likely using a hamburger menu for mobile.
