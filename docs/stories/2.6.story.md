## Story

As a user, I want to see a clear disclaimer section on the page, so that I understand any important terms, conditions, or additional information related to the certificate or event.

## Acceptance Criteria

1.  A new React component named `DisclaimerSection` is created in the `apps/web/src/components/sections/` directory.
2.  The component must be responsive and display correctly across all screen sizes (mobile, tablet, desktop).
3.  The component must render the `label`, `headline`, `description`, and `cta` button text as defined in the `disclaimer` section of `content.json`.
4.  All styling (e.g., typography, colors, spacing, button styles) must be implemented using Tailwind CSS and adhere to the specifications in `style.json`.
5.  The CTA button within the section should be a reusable `Button` component from the established UI library (`shadcn/ui`).
6.  The `DisclaimerSection` component is imported and rendered in the main `LandingPage` component (`apps/web/src/app/page.tsx`).
