## Story

As a user, I want to see a consistent and informative footer at the bottom of every page, so that I can easily find copyright information and access important links.

## Acceptance Criteria

1.  A new React component named `Footer` is created in the `apps/web/src/components/sections/` directory.
2.  The component must be responsive and display correctly across all screen sizes (mobile, tablet, desktop).
3.  The component must render the `logoIcon` and `copyrightText` as defined in the `footer` section of `content.json`.
4.  The component must dynamically render a list of links by mapping over the `footer.links` array from `content.json`.
5.  Each rendered link must display its `name` and link to its corresponding `href`.
6.  All styling (e.g., layout, typography, colors) must be implemented using Tailwind CSS and adhere to the specifications in `style.json`.
7.  The `Footer` component is imported and rendered in the main `LandingPage` component (`apps/web/src/app/page.tsx`).
