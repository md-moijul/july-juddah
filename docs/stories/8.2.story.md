# Story 8.2: Backend - Create getUserById Server Action

**Status:** Draft

**Epic:** [Refactor User Data and State Management](docs/prd/epic-8-refactor-user-data-and-state-management.md)

**Story:** As a developer, I want to create a secure `getUserById` Server Action so that the client can fetch the full user object from the database using a `userId`.

**Acceptance Criteria:**

1.  A new server action `getUserById(userId: string)` is created and exported from `apps/web/src/app/_actions/user.ts`.
2.  The action securely queries the database to find a user by their `userId`.
3.  The action returns the full user object (`{ id, name, town, phone }`) if the user is found.
4.  The action returns `null` if the user is not found.
5.  The action includes appropriate error handling.

**Tasks / Subtasks:**

-   [ ] Locate the server actions file at `apps/web/src/app/_actions/user.ts`.
-   [ ] Define and export the `getUserById` server action.
-   [ ] Implement the database query to find the user by ID.
-   [ ] Add error handling to the database query.
-   [ ] Ensure the action returns the user object or `null` correctly.

**Dev Notes:**

*   This is a backend-only story. No UI changes are expected.
*   Ensure the database query is protected against SQL injection if not using an ORM that handles it automatically.

**Testing:**

*   The action should be manually tested to ensure it correctly retrieves a user and handles the not-found case.
