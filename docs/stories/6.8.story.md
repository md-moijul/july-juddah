### Acceptance Criteria

2.  All test files follow the `*.test.tsx` naming convention.
3.  All tests are structured using the "Arrange, Act, Assert" pattern.
4.  All tests are written from a user's perspective using React Testing Library.
5.  All mocks use `jest.fn()`.
6.  The `__tests__` directory is removed.

### Dev Notes

**Testing Standards**

*   **File Location:** All test files MUST be co-located in the same folder as the source file they are testing. [Source: docs/prd/epic-6-testing-refactor-and-standardization.md]
*   **File Naming Convention:** All test files must follow the `*.test.tsx` naming convention. [Source: docs/prd/epic-6-testing-refactor-and-standardization.md]
*   **Test Structure (Arrange, Act, Assert):** All tests must be structured with the following three distinct sections for clarity and consistency. [Source: docs/prd/epic-6-testing-refactor-and-standardization.md]
*   **Testing Philosophy:** Tests should be written from a user's perspective, focusing on the component's behavior as experienced by the user. Utilize the React Testing Library. [Source: docs/prd/epic-6-testing-refactor-and-standardization.md]
*   **Mocking Strategy:** Use `jest.fn()` for mocking server actions, API calls, and custom hooks. [Source: docs/prd/epic-6-testing-refactor-and-standardization.md]
