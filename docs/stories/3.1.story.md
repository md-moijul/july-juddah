### Goal
Perform the foundational setup for the architectural refactor. This story involves updating `globals.css` with design tokens from `style.json`, deprecating the old `tailwind.config.ts` theme extensions, and creating a new centralized `content.ts` file. No existing components should be modified in this story.

### Tasks
- [ ] Update `apps/web/src/app/globals.css` to match the structure and variable names of `docs/assets/example.css`, populating the values by overriding with tokens from `apps/web/src/data/style.json`.
- [ ] Deprecate `apps/web/tailwind.config.ts` by removing the `theme.extend` object and adding a deprecation notice.
- [ ] Create the new `apps/web/src/lib/content.ts` file and populate it with the content from `apps/web/src/data/content.json`.
