### Goal
Perform the foundational setup for the architectural refactor. This story involves updating `globals.css` with design tokens from `style.json`, deprecating the old `tailwind.config.ts` theme extensions, and creating a new centralized `content.ts` file. **No existing components should be modified in this story.**

### Acceptance Criteria
1.  `apps/web/src/app/globals.css` is updated to match the structure and variable names of `docs/assets/example.css`.
2.  The CSS variables in `globals.css` are populated with the corresponding values from `apps/web/src/data/style.json`.
3.  The `theme.extend` object in `apps/web/tailwind.config.ts` is removed.
4.  A deprecation notice is added to `apps/web/tailwind.config.ts`.
5.  A new file is created at `apps/web/src/lib/content.ts`.
6.  The `content.ts` file is populated with the content from `apps/web/src/data/content.json` in a strongly-typed format.
7.  No existing components are modified.
8.  The application still runs and displays correctly after these changes.
