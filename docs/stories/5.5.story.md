### Status
- Ready for Review


### Story
**As a** user,
**I want** to fill out and submit a simple form in the "Order Hard Copy" tab,
**so that** I can order a physical copy of my certificate.

### Acceptance Criteria
1. A new `HardCopyTab` component is created and implemented within the `Tabs` on the `/generate` page.
2. The form within the tab contains inputs for `name`, `phone number`, and `shippingAddress`.
3. The `name` and `phone number` fields are pre-populated with data from the parent page if it exists.
4. The form includes a confirmation checkbox (e.g., "I confirm my address is correct").
5. The "Confirm Order" button is disabled until all required fields are filled and the checkbox is ticked.
6. Clicking the "Confirm Order" button calls a new, dedicated Server Action to create the order.
7. Upon successful order creation, a confirmation message is displayed to the user.

### Tasks / Subtasks
- [x] **Task 1: Create New Server Action** (AC: #6)
    - [x] Create a new file `apps/web/src/app/actions/order.ts`.
    - [x] Implement a new server action `createOrder`.
    - [x] The action should accept `name`, `town`, `phone`, and `shippingAddress`.
    - [x] Inside the action, find the user by `phone` in the `users` table.
    - [x] If the user exists, create a new order in the `orders` table linked to the `userId`.
    - [x] If the user does not exist, create a new user first, then create the order.

- [x] **Task 2: Create `HardCopyTab` Component** (AC: #1, #2, #3, #4, #5)
    - [x] Create a new file `apps/web/src/components/HardCopyTab.tsx`.
    - [x] The component should accept `name`, `town`, and `phone` as props.
    - [x] Implement a form with inputs for `name`, `phone number`, `town`, and `shippingAddress` using shadcn components.
    - [x] Pre-populate `name` and `phone number` from the props.
    - [x] Add a confirmation checkbox using shadcn Checkbox.
    - [x] Implement client-side validation to disable the "Confirm Order" button until all fields are filled and the checkbox is ticked, including `town`.
    - [x] Implement error display for order creation failures.

- [x] **Task 3: Integrate Server Action** (AC: #6, #7)
    - [x] In `HardCopyTab.tsx`, import the `createOrder` server action.
    - [x] The "Confirm Order" button's `onClick` handler should call the `createOrder` action.
    - [x] The handler should manage loading and success/error states.
    - [x] On success, display a "Order Confirmed!" message.

- [x] **Task 4: Update Tabs on `/generate` page** (AC: #1)
    - [x] Import and include the `HardCopyTab` component within the `Tabs` component on the `/generate` page.
    - [x] Pass the necessary props (`name`, `town`, `phone`) to the `HardCopyTab` component.

### Dev Notes
- The new server action in `apps/web/src/app/actions/order.ts` is critical. It must handle both existing and new users gracefully.
- The `HardCopyTab.tsx` component should be self-contained and manage its own state for the form fields and checkbox.
- Ensure that the "Confirm Order" button's disabled state is correctly managed based on form validation.
- The success message should be clear and provide a good user experience.

#### Testing
- Test the `createOrder` server action directly to ensure it correctly creates users and orders.
- Write unit tests for the `HardCopyTab` component to verify form validation and state management.
- Write an integration test to ensure the `HardCopyTab` component correctly calls the server action and displays the success message.
