# Story 4.2: Redesign /generate Page for New User Flow

**Status:** Done

**Story:**
As a user, I want a clear, two-step process on the `/generate` page to enter my name and select my district, so that I can easily create my personalized certificate.

**Acceptance Criteria:**
1.  The `/generate` page UI is updated to remove the old input fields.
2.  The new UI presents a text input field for "What is your name?".
3.  Below the name input, a dropdown menu is displayed for "Select which Town you've participated in".
4.  The dropdown is populated with the 64 districts of Bangladesh.
5.  A "Generate Certificate" button is present.
6.  After clicking the button and providing valid inputs, the generated certificate image is displayed on the page.
7.  Below the certificate, two buttons are visible: "Download E-certificate" and "Get a Hard Copy".

**Tasks / Subtasks:**
- [x] Create a JSON file or constant array containing the list of 64 districts of Bangladesh.
- [x] Update the React component for the `/generate` page.
- [x] Replace existing form elements with a new text input for name and a dropdown for the district.
- [x] Implement the client-side logic to handle user input.
- [x] Implement the "Generate Certificate" button's `onClick` handler to call the backend PDF generation service.
- [x] Add a state to display the generated certificate image on the page.
- [x] Add the "Download E-certificate" and "Get a Hard Copy" buttons, initially they can be disabled or placeholders.

**Dev Notes:**
- The list of districts should be easily updatable.
- The UI should be responsive and match the existing site's style.
