## Story

As a user, I want to see a visually appealing image banner on the homepage that reinforces the event's theme, so that the page feels more engaging and professional.

## Acceptance Criteria

1.  A new React component named `ImageBanner` is created in the `apps/web/src/components/sections/` directory.
2.  The `ImageBanner` component must be responsive and display correctly on mobile, tablet, and desktop screens.
3.  The component will display the image specified in the `content.json` file for the `imageBanner` section.
4.  The styling for the banner (e.g., layout, spacing, etc.) must be implemented using Tailwind CSS and adhere to the design specifications in `style.json`.
5.  The `ImageBanner` component is imported and rendered in the main `LandingPage` component (`apps/web/src/app/page.tsx`).
