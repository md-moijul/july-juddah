# Epic 3: Architectural Refactor & Tokenization

**Goal:** Refactor the existing frontend codebase to align with modern Tailwind CSS v4 best practices by tokenizing styles and centralizing content. This will improve maintainability, scalability, and developer experience.

## Stories

*   **Story 3.1: Initial Setup for Architectural Refactor:** Perform the foundational setup for the refactor, including updating `globals.css` with design tokens, deprecating the old theme configuration, and creating a centralized content file. This story will not modify any existing components.
*   **Story 3.2: Refactor Certificate Preview Component:** Refactor the Certificate Preview component to use the new tokenized styles and centralized content.
*   **Story 3.3: Refactor Counter Section Component:** Refactor the Counter Section component to use the new tokenized styles and centralized content.
*   **Story 3.4: Refactor Disclaimer Section Component:** Refactor the Disclaimer Section component to use the new tokenized styles and centralized content.
*   **Story 3.5: Refactor Features Section Component:** Refactor the Features Section component to use the new tokenized styles and centralized content.
*   **Story 3.6: Refactor Final CTA Section Component:** Refactor the Final CTA Section component to use the new tokenized styles and centralized content.
*   **Story 3.7: Refactor Footer Component:** Refactor the Footer component to use the new tokenized styles and centralized content.
*   **Story 3.8: Refactor Hero Section Component:** Refactor the Hero Section component to use the new tokenized styles and centralized content.
*   **Story 3.9: Refactor Image Banner Component:** Refactor the Image Banner component to use the new tokenized styles and centralized content.
*   **Story 3.10: Refactor Navigation Component:** Refactor the Navigation component to use the new tokenized styles and centralized content.
*   **Story 3.11: Refactor Premium Items Section Component:** Refactor the Premium Items Section component to use the new tokenized styles and centralized content.
